# The request row is outlined buttons spread across, each with its key hint

The owner on hub/T-419: "I kind of want to have those be keyboard shortcuts and maybe spread them out with some text instead... turn what's left into that same text. So it could be like what's left, prototype, grill, visual, and then just the attachments icon remains." Of the three takes drawn (plain words, outlined buttons, words with a suffix hint) they picked "Outlined buttons, spread." This amends [each question has the thread's request row](2026-11-15-0730-each-question-has-the-threads-request-row.md), whose eye, fire and image are now words.

- **One helper draws the row.** `BoardUI.requestRow(id, {quick, protoLabel, requests})` (`board/public/ui.js`) is small outlined buttons of equal width, What's left? (`quick: true`, a thread's reply box only), Prototype, Grill and Visual, then the attach icon, the only icon left. A thread's reply box draws it on its own line above Send; each open question and the New task box draw it under their note box without What's left?. The buttons keep `data-quick`, `data-proto`, `data-grill` and `data-visual`, so every tap handler is as it was.
- **Each word has an Alt+letter**, ⌥L, ⌥P, ⌥G and ⌥V (`Alt+` off a Mac), shown as a faint hint inside the button at the right wherever send buttons show their keys (a keyboard and room; none on a phone). `BoardUI.keyedRequest` finds the button by `ev.code`, and the box's keydown clicks it, so a word pressed with text in the box sends that request with the text, as a tap does. A button disabled while files upload is not pressed.

Considered: bare letters when the box is empty. They can only send a bare request, never one with typed text, and they block starting a reply with those letters, so the modifier scheme won.
