# The request row is outlined buttons spread across, each with its key hint

The owner on hub/T-419: "I kind of want to have those be keyboard shortcuts and maybe spread them out with some text instead... turn what's left into that same text. So it could be like what's left, prototype, grill, visual, and then just the attachments icon remains." Of the three takes drawn (plain words, outlined buttons, words with a suffix hint) they picked "Outlined buttons, spread." This amends [each question has the thread's request row](2026-11-15-0730-each-question-has-the-threads-request-row.md), whose eye, fire and image are now words.

- **One helper draws the row.** `BoardUI.requestRow(id, {protoLabel, review})` (`board/public/ui.js`) is small outlined buttons of equal width: Prototype, Grill and Visual, and Review in a thread's reply box. The attach icon is not in the row: [it sits inside the text box](2026-11-16-0730-the-attach-icon-sits-inside-the-text-box.md). A thread's reply box draws it on its own line above Send; each open question and the New task box draw it under their note box. The buttons keep `data-proto`, `data-grill` and `data-visual`, so every tap handler is as it was.
- **A word that doesn't fit ends in …** (hub/T-558). Each word sits in its own `.req-word` span that clips with an ellipsis, beside the key hint, so the equal-width buttons never spill. Only this row does it; no other board button spilled.
- **What's left? is gone** (hub/T-558, the owner: "Drop whats left button, doesn't fit"), with its ⌥L. It only sent the text "What's left?" as a message, so typing it asks the same; there is no /left command.
- **Each word has an Alt+letter**, ⌥P, ⌥G and ⌥V (`Alt+` off a Mac), shown as a faint hint inside the button at the right wherever send buttons show their keys (a keyboard and room; none on a phone). `BoardUI.keyedRequest` finds the button by `ev.code`, and the box's keydown clicks it, so a word pressed with text in the box sends that request with the text, as a tap does. A button disabled while files upload is not pressed.

Considered: bare letters when the box is empty. They can only send a bare request, never one with typed text, and they block starting a reply with those letters, so the modifier scheme won.
