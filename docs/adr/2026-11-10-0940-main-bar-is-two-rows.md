# Main's bar is two rows

Main's bar keeps each control in its own steady place. Row 1 is the repo's owner/name with Visit (or Install) right-justified. Row 2 is branch@sha of the commit being served, its age as muted text from `BoardUI.lasted`, and the refresh icon, with Updating… (spinner) or Update failed right-justified, and nothing when ready.

- The state words are the same with no old server to replace: always Updating… and Update failed.
- Capitalized to match the cards' Visit and Install badges, per the owner's answer on card #501.
- Update failed stays the red button that opens main's build log.
