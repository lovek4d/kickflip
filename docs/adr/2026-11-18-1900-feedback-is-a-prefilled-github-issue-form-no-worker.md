# Feedback is a prefilled GitHub issue form, no Worker

`kickflip feedback` opens GitHub's new-issue form (`.github/ISSUE_TEMPLATE/feedback.yml`) with the type, title and the kickflip, node and OS versions in the URL. The person writes the details in the browser under their own GitHub account.

The owner picked this over a kickflip.sh Worker that files issues on the person's behalf (11/18): no server to run, no token to hold, and nothing from boards, paths or hosts leaves the machine. The Worker stays a later step if the form proves too limited.
