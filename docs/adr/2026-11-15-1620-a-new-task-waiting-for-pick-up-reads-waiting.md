# A New task waiting for pick-up reads "waiting…"

A New task reads "sending…" (grey) while it goes out, "waiting…" (grey, counting up) until the orchestrator picks it up, then "processing..." (blue). The grey word between was "triaging"; it now reads "waiting…", the word every other pick-up wait on the board uses, so a pending owner action has one name from send to pick-up.
