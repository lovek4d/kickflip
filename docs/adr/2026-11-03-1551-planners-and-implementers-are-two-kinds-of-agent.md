# Planners and implementers are two kinds of agent

An agent on a card is a **planner** or an **implementer**. Planners are the grill and prototype agents: they write no output code. Every other kind (claude, codex, install, …) is an implementer. `board/domain.mjs` `plans` and `builds` tell them apart. The words are for code and ADRs; the screen says what each agent does.

- **Blue lines.** A planner's status line and its agent started line are a darker ink of the owner's bubble blue, `--love-ink` beside `--love` in `shared/colors.css`, dot included, distinct from the accent blue of new messages (since [one human blue](2026-11-03-1627-one-human-blue.md) the accent is this blue). Its finished line stays green. `builder start` and `builder progress` mark a planner's status lines `planner: true` in the thread file (`board/store.mjs` `statusToThread`); the thread and the card draw a marked line with the `planner` class.
- **The card.** While only planners run, the card's builder line is theirs, in that blue: dot, latest status, time ago, in Todo as anywhere. While a build runs too, the build's line wins, orange, and the planner shows in the thread only (`builderOf`). A planner never draws phase bars. It stalls as a builder does, red Stalled at 30 minutes, tap to nudge.
- **Model.** `builder start` saves `--model` for a planner as it does for kind claude, defaulting to Sonnet for a prototype and Opus for a grill; a dispatched planner's model stays through the agent's own start. The hub's Claude model doesn't rule a planner's ([usage picks Opus, Auto or Sonnet for Claude builders, and builder pick says which and why](2026-11-03-1526-usage-picks-opus-auto-or-sonnet-for-claude-builders.md)). The agent line names it by model and kind: "Claude Sonnet prototype started", "Claude Opus grill started". A further planner's status line is named by its kind: "Prototype building: …".
- **Idle pull.** Only a running build keeps a board from being idle. A running planner doesn't stop "Pull in Todo cards when idle" from starting the next ready card (`pullOf`); a card being grilled or prototyped is still not pullable itself ([a new card is ready, grilling or prototyping, and reads ready in green when it is](2026-11-03-0516-a-new-card-is-ready-grilling-or-prototyping.md)).

This amends [colour says who's waiting](2026-11-01-1817-colour-says-whos-waiting.md), whose orange covered every builder line, and [a new card is ready, grilling or prototyping, and reads ready in green when it is](2026-11-03-0516-a-new-card-is-ready-grilling-or-prototyping.md)'s rule that a running grill or prototype agent keeps the board from being idle.
