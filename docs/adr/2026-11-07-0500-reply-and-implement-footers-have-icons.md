# Reply and Implement footers lead with an icon

A Todo thread message's footer names the button it was sent with, and a bare Implement is a request line. Grill, Prototype and Quick build lines lead with a mark from `MARK_ICONS`; Reply and Implement had none, so their footers started flush with the words. `MARK_ICONS` now has a reply arrow for Reply and code brackets for Implement. Quick build already had its lightning.
