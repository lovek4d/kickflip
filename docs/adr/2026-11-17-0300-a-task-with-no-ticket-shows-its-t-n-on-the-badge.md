# A task with no ticket shows its T-<n> on the badge

Supersedes the badge line of [a task is a card with no ticket keyed T-n](2026-11-09-1500-a-task-is-a-card-with-no-ticket-keyed-t-n.md) and the "quiet `Task` badge" read in [work items are tasks](2026-11-13-1126-work-items-are-tasks-and-tickets-attach-to-them.md).

A task with no ticket shows its `T-<n>` as the quiet badge's label, where it showed `Task` with the `T-<n>` only in the tooltip. The number is what the owner names a task by, so it belongs on the badge. The tooltip stays "T-<n> · a task, no ticket". Once the task has a ticket, the badge shows the ticket's id as before; an internal task already showed its key.
