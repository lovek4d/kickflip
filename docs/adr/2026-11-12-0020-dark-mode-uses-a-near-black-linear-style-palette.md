# Dark mode uses a near-black, Linear-style palette

Dark mode's ground in shared/colors.css moves from #111114 to near-black: --bg #0b0c0d, --panel #111214, --line #212226, --text #e8e9ec, --muted #8a8f98, --chip #1a1b1e, --band #141517, --claude #1f1a12, --accent-soft #141b26. This is take A of the dark-palette prototype round (the owner picked it over a soft charcoal and a pure black).

The semantic colours (--accent, --ok, --warn, --bad, --purple) are unchanged, so red > orange > blue > green > grey still reads on the darker ground. Light mode is untouched. A pure-black OLED mode is its own card (T-136).
