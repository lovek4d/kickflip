# UI tests freeze Date in their sandbox

Card #660, fix task F7 of docs/test-determinism-audit.md. The board's and hub's renderers read the clock themselves: `ago`, `since`, `lasted`, `shortSince`, the usage clock, a hold's day, a busy host's minutes. ui.test.mjs and view.test.mjs built their data from the real clock and asserted the words those renderers drew from it again, so a stall between the two could change the words: "busy under a minute" had one second of slack, a hold's "today" flipped across midnight, and a Hold sheet's chip labels flipped across a minute.

- **The sandbox's Date stands still.** shared/fixed-clock.mjs's `fixedDate(clock)` is a Date whose `new Date()` and `Date.now()` read `clock()`. ui.test.mjs hands one fixed at its `NOW` to every vm context it runs page scripts in. view.test.mjs's `fakePage` hands one that starts at `NOW` and moves only by the page's `advance(ms)`, with its `performance.now`. Each file builds its data from `NOW`, a local noon, so a day either side of it is still one day.
- **Renderers don't take `now`.** The audit proposed giving each renderer that reads the clock a `now` option. That reached well past the renderers it named (the usage clock, the hub page, review lanes, questions, prompts, threads), and a renderer added later without one would read the real clock again unnoticed. A frozen sandbox Date fixes every clock read, current and future, with no product signature change. The renderers that already took `now` (`etaLine`, `cardTime`, `heldUntilWords`, `holdPicker`, `sidebar`, `startCaption`, `failedStart`) keep it.
- **A spawned script takes it by `--import`.** Loaded by `node --import shared/fixed-clock.mjs` with `KICKFLIP_TEST_NOW` set, the module fixes the process's own Date. hooks-plugin/hooks/board-messages.test.mjs runs its hook so, and asserts the ages ("3 min ago", "just now") and the ask edit's restamped working mark exactly.
- **Fake chains drain by turns, not a clock.** view.test.mjs's waits on its fake fetch and IndexedDB chains are `drain(done, what)`: event-loop turns until `done()` holds, failing after 1000 turns. Those fakes answer in promise jobs and event-loop turns, so a chain that hasn't finished in that many never will; each finished within 20 when measured. The hub test that spawns hub.mjs keeps its `until` until the hub runs in process (F2).
- **Records' own times.** board/board-builder.test.mjs's SubagentStop hook tests write their transcript times from the builder records' own `started`, not the real clock, so the CLI spawns before them can't move a start out of its command's window.
