# Each Todo card sits under one filter box

Amends [the Todo header has a filter](2026-11-12-0600-the-todo-header-has-a-filter.md), whose "No precedence" rule goes.

With one box per property, a blocked card was also ready or discussing, so with only Blocked checked its phase box hid it and Blocked alone showed nothing, while unchecking only Blocked hid the same cards.

- **One box per card.** Blocked if the card is blocked (by tasks, a condition or the owner), else its phase's box: Ready (ready, staging), Discussing (discussing, new), Planning (grilling, prototyping). The boxes partition the lane.
- **Unchecking a box hides exactly its cards**, and Blocked alone shows the blocked cards.
- The order, blocked over phase, is the Colour rule's precedence. The "N of M" count is unchanged.
