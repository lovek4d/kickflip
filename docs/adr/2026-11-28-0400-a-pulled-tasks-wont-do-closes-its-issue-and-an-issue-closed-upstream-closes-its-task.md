# A pulled task's won't-do closes its issue, and an issue closed upstream closes its task

Owner, 11/27, from the issue pull's grill: an issue closed or deleted upstream closes its unstarted task Done, and a started task gets a thread line; a pulled task closed Done with no build closes its issue as not planned on GitHub, or canceled on Linear.

- **Upstream close.** The hub's GitHub poll (`hub/issue-pull.mjs closeGone`) compares each open task whose ticket is an issue of its board's repo (a GitHub ticket source) with the repo's open issues. A task whose issue is not among them is closed Done when no build has started it (`board/cards.mjs issueClosedUpstream`: still in Todo, with no builder record, branch, PR, push or merge-ready mark), with the line "Issue #n closed upstream, so this task closed." Its ticket is left alone, since it is already closed. A started task gets "Issue #n closed upstream; this task was already started." once, and nothing else changes. This covers every task whose ticket is in the board's source, pulled or not.
- **The list is trusted only when complete.** The poll lists the newest 100 open issues with their total. When the repo holds more open issues than were listed, a missing ticket may be an older open one, so nothing closes until the total is 100 or fewer.
- **The query.** A board with the pull off adds its repo to the poll's query only while one of its open tasks has a `#n` ticket, so the poll can see it closed. This replaces the earlier rule that a board with the pull off adds nothing.
- **Won't-do.** A task the pull filed carries `ticket_pulled`. Closed Done with no build behind it (nothing landed or merged, no builder record, branch, PR, push or merge-ready mark), its ticket target is `wontdo`: `gh issue close --reason "not planned"` on GitHub, a canceled-type state on Linear. The thread line reads "Closed #n as not planned." The assignee rule is lifted for it, so an unassigned issue the owner pulled in still closes; a build's Done keeps the usual rule, which leaves an unassigned issue open. A failed close is retried by the hub's poll like any ticket close.
