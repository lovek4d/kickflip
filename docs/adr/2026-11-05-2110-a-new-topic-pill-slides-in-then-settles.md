# A new topic's pill slides in, then settles

Status: accepted (owner answered gh247-pill, take A, 11/05)

#248 made a topic that arrives on Open questions insert its pill in place with no repaint, so the open topic, picks, half-typed note and scroll stay. This adds how the owner notices it: the new pill gets the `arrived` class, which slides it in with a brief glow and settles. No dot and no jump chip (takes B and C). The animation runs only when the system allows motion.
