# Done is a ticket action in every lane

The open task's upper row, the **ticket actions**, holds the buttons that change the task itself: Done, Block or Unblock, Implement, Merge. The thread box's row, the **thread actions**, holds the ones that ask for work in the thread: What's left?, Prototype, Grill, Visual, Review.

Done showed in the ticket actions only on a Todo task, and an In Review task had it only in the thread box beside Reply. It now shows in the ticket actions of every work task outside Done, right of Block, as Block shows in both rows while In Progress. An In Review task keeps its thread box Done too. Both go through the one `finish` confirm and `card-done` send, in the same tone.
