# A card's external links share the last details line

An open card's details list ends with **Notes ↗ · Install ↗ · Review on GitHub ↗**, each only when it applies, with Review last. These links share the full width and wrap between links when needed; Hold, Grill, Merge and the other workflow buttons stay in their own row below. This placement keeps the links together without another button row on a phone, following the owner's chosen details-line prototype.

Review on GitHub keeps its notice orange while it clears Action needed, and otherwise uses plain link styling. Install keeps its current, older-build, inert Building… and confirming Rebuilding… states; the lane card's badges keep their placement and appearance. Notes still has no summary. This replaces the separate Notes row in [0062](0062-notes-is-a-link-in-the-details-list.md) and the open card's Install button placement in [0051](0051-a-device-app-card-carries-an-install-link.md).
