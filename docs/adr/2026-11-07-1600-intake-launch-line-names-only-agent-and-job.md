# The intake launch line names only the agent and its job

The line `launchIntake` (headless.mjs) writes in the card's thread reads "Claude Sonnet intake triage", with the thread's own time, instead of "Intake triage launched on Claude Sonnet in <repo>." It keeps its status kind and its log link. Planners, builders and landers post no launch line since the run's fold ends with a log link (2026-11-07-1500-a-runs-fold-ends-with-a-log-link).
